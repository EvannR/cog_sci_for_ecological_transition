# Abstract

Introduction d'un numéro thématique (14 articles) sur la théorie des behaviour settings. Les sciences cognitives reconnaissent le rôle de l'environnement (cognition située, distribuée) sans en avoir de description systématique. Les behaviour settings de Barker restent le compte rendu le plus discipliné de l'écosystème comportemental humain.

# Key claims / thesis

- Il faut une écologie du comportement humain : décrire l'environnement social et matériel aussi rigoureusement que l'individu.
- Psychologues écologiques : déplacer l'unité d'analyse de l'organisme vers le système organisme-environnement.
- Le numéro discute les limites (technologie, rapport individu / collectif) et les extensions.

# Methods

Editorial et présentation des articles.

# Main findings

- Exemples du numéro : outils pour des settings mêlant éléments physiques et numériques, architecture d'un bâtiment pour personnes sans abri pensé comme setting qui soutient l'agentivité.
