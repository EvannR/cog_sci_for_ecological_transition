# Abstract

Cadre conceptuel de l'UNICEF pour les programmes de changement social et comportemental (CSC). Synthèse de théories du comportement et de la décision, condensée dans un modèle de facteurs (Behavioural Drivers Model, BDM) en trois catégories : psychologie, sociologie, environnement. Chaque facteur est relié à des approches d'intervention, pour le diagnostic, la conception et l'évaluation des programmes.

# Key claims / thesis

- Les fondements théoriques des interventions sont souvent implicites => interventions par défaut (une campagne de communication pour tout problème).
- Deux questions : pourquoi les gens font ce qu'ils font, comment influencer ce qu'ils font.
- Trois catégories de facteurs : psychologie (biais cognitifs, intérêt, attitude, auto-efficacité, intention...), sociologie (familles, communautés, normes), environnement (institutions, politiques, services, infrastructures, information).
- Modèle volontairement agnostique, applicable à tous les secteurs.

# Methods

Synthèse de 25 perspectives, théories et modèles, avec le groupe sur les normes sociales de l'Université de Pennsylvanie, prétests dans plusieurs pays (Egypte, Liban, Sénégal, Sierra Leone, Ouganda, Zimbabwe).

# Main findings

- Outil opérationnel pour les praticiens, lié à d'autres guides UNICEF (normes sociales, mesure des facteurs).
