# Abstract

Les études sur les mécanismes du changement de comportement supposent implicitement un changement linéaire, constant et causé par des influences indépendantes (techniques de changement). Les auteurs montrent les limites de ces outils et proposent une approche par systèmes complexes adaptatifs : interconnexion, non-ergodicité, non-linéarité. Ils présentent la Recurrence Analysis pour l'analyse de séries temporelles non linéaires.

# Key claims / thesis

- Les interventions produisent rarement des effets durables, surtout quand on les transfère d'un contexte à l'autre.
- Les modèles linéaires (régression, ANOVA) supposent des changements graduels et proportionnels, hypothèses en général violées.
- Non-ergodicité : ce qui vaut en moyenne pour une population ne vaut pas pour chaque individu dans le temps.
- Vue systèmes complexes : une intervention est un choc sur le système, qui pousse contre des forces existantes.
- Il faut des designs longitudinaux intensifs au niveau individuel.

# Main findings

- Quand un modèle explique mal le comportement, ce n'est pas forcément une variable manquante ou une mesure grossière : les hypothèses du modèle peuvent être fausses.
