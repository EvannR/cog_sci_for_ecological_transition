# Abstract

Revue interdisciplinaire sur l'« opinion agrégée » (sondages, notes, likes, votes) : comment les individus tirent des inférences sur le monde. Philosophie (ce qui la distingue d'autres preuves), science politique (origine dans le jugement collectif), psychologie (se conformer, apprendre ou ignorer). Propose le modèle « paths to persistence ».

# Key claims / thesis

- L'opinion agrégée est une information sociale impersonnelle, à une échelle inédite, qui demande d'autres compétences que le témoignage individuel.
- La question n'est pas si l'opinion change les croyances, mais quand et par quels mécanismes.
- Quatre chemins de persistance : informationnel (les autres sont ignorants ou biaisés), fonctionnel (changer coûte socialement), ontologique (question jugée subjective ou inconnaissable), computationnel (limites cognitives).
- Communiquer un consensus (ex. scientifique sur le climat) a des effets faibles parce que ça ne touche que le chemin informationnel => interventions adaptées aux raisons propres à chaque personne.

# Methods

Revue narrative interdisciplinaire. Données surtout américaines.

# Main findings

- Les gens se conforment, apprennent ou ignorent selon le nombre, la fiabilité et l'indépendance des informateurs.
- Peu de travaux relient opinion, inférence et action (mais le comportement reste peu étudié ici).
