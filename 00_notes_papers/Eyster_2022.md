# Abstract

Synthèse de 86 théories de l'action humaine issues des sciences humaines et sociales. Les auteurs dégagent 8 métathéories (hypothèses de fond) qui organisent ces théories au-delà des disciplines, et indiquent pour chacune le type de problème qu'elle éclaire, avec des exemples sur le climat.

# Key claims / thesis

- Les théories sont fragmentées par discipline, avec leur jargon et leurs hypothèses implicites => on choisit la théorie familière (souvent la TPB), pas la plus adaptée.
- 8 métathéories : Independent Self, Independent Structure, Cognitive Needs, Psychological Needs, Communal Needs, Economic Needs, Top-Down, Interdependent.
- Sept sur huit supposent une relation simple variable indépendante => variable dépendante. Seule Interdependent intègre les rétroactions.
- Top-Down (économie politique, critique) identifie les causes systémiques mais prescrit rarement des interventions.
- Interdependent (sociologie, anthropologie, pratiques) traite les interactions mais donne peu de prédictions.
- Aucune métathéorie ne suffit : les combiner.

# Methods

Sélection de théories dans de nombreuses disciplines, catégorisation inductive selon les facteurs supposés générer l'action.

# Main findings

- La psychologie est moins interdisciplinaire que la plupart des autres champs.
- Exemple Interdependent : le vélo comme pratique (compétences, disponibilité, sens, technologie) plutôt que comme choix.
